# Локальное приложение внутри Bitrix

Файлы готовы к установке; запись приложения в портале ещё не создана. Регистрация выполняется администратором в интерфейсе вашего Bitrix. Она не требует публикации в Маркетплейсе.

1. Сначала обновить дашборд обычным `deploy-dashboard.sh`: он также разместит `app.php` и `app-install.php` с резервной копией старой страницы.
2. В Bitrix открыть «Приложения / Маркет» → «Разработчикам» → «Другое» → «Локальное приложение». Названия пунктов могут отличаться в вашей версии; выбрать серверное приложение с интерфейсом, а не входящий вебхук и не режим «Только API».
3. Название: **Дашборд Бавария**.
4. URL обработчика: **https://crm.bavaria-pavlodar.kz/dashboard-oksana-v1/app.php**.
5. URL первоначальной установки: **https://crm.bavaria-pavlodar.kz/dashboard-oksana-v1/app-install.php**.
6. Не запрашивать CRM/задачи/диск и другие REST-права, которыми приложение не пользуется. Если форма требует базовое право профиля, выбрать только его. Данные читаются штатным PHP API с правами текущей сессии пользователя 5.
7. Сохранить приложение и завершить установку в его окне. Обработчик установки доступен администратору Bitrix и не читает показатели. Дашборд и API по-прежнему доступны только Оксане (ID 5); администратор-установщик не получает доступ к ним.
8. Открыть созданное приложение из списка приложений. Если нужен отдельный пункт слева, использовать настройку меню Bitrix и реальную ссылку открывшегося приложения — ID приложения до регистрации неизвестен, его нельзя подставлять наугад.

Все страницы и API сохраняют проверку пользователя 5. Если форма портала позволяет настроить круг пользователей приложения, выбрать только Оксану. Другие сотрудники не смогут получить данные даже при наличии прямой ссылки. Рамки разрешены только в том же домене (`SAMEORIGIN`); защита не отключается.

Обычная страница `index.php` продолжает работать. `app.php` включает официальный JS SDK Bitrix24 для подстройки высоты окна. Адрес SDK: `https://api.bitrix24.com/api/v1/`; браузеру нужен доступ к этому домену. OAuth-параметры, приходящие от портала, не сохраняются и не выводятся; client secret, токены и вебхуки в код добавлять не нужно. Приложение рассчитано на существующую браузерную сессию в этом же портале и не предназначено для других порталов.

Проверить после регистрации: вход Оксаны, отсутствие доступа у другого пользователя, диапазон дат, выбор воронки, переходы к сделкам и высоту окна. Закрытие приложения не останавливает CRM. Удаление локального приложения из портала не удаляет данные CRM; файлы самостоятельной страницы остаются.
